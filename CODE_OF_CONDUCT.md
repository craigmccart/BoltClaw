# Code of Conduct

## The short version

Be decent. BoltClaw is a small open source security project, not a battleground.

## Expected behaviour

- Assume good faith. Most disagreements in security tooling are about
  threat models, not about people.
- Give and take criticism on the work, not the person. "This pattern will
  false-positive on X" is useful. "This is amateur" is not.
- Respect that maintainer time is donated. A well-formed issue with clear
  steps to reproduce is worth more than a follow-up asking for an update.

## Unacceptable behaviour

- Harassment, personal attacks, or discriminatory language of any kind.
- Publishing others' private information.
- Deliberately filing misleading reports.
- Sustained disruption of discussions.

## Responsible use

BoltClaw is a defensive tool and its test fixtures include a deliberately
malicious example skill. It is there so the scanner can be tested against
it. Using this repository to coordinate attacks on systems you do not own
or have permission to test is out of bounds and will get you removed.

## Reporting

Report conduct problems privately to the maintainer using the contact
details in [SECURITY.md](SECURITY.md). Reports are handled confidentially.

## Enforcement

The maintainer may edit, hide, or delete comments, and may block accounts,
for behaviour that breaches this document. Decisions are at the maintainer's
discretion and are final.
